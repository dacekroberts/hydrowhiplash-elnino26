## Methods notes for the freeze

Decisions for the owner, not defects:

- **Block bootstrap and persistence.** Blocks of 3 years break up longer
  persistence, so statistics that depend on it are understated: on a
  synthetic random walk the 95% interval for the lag-1 autocorrelation (0.30
  to 0.70) did not contain the estimate (0.84). Suited to means and
  regression coefficients; worth checking which tests `ANALYSIS_PLAN.md`
  applies it to.
- **El Niño definition.** One DJF value, per the plan, differs from NOAA's
  operational definition (five consecutive overlapping seasons ≥ +0.5);
  worth one line on the methods page.
- **Percent differences.** `describe.phase_summary` divides by the mean, so
  for anomaly variables centred near zero (SPEI, temperature anomalies) only
  the standard-deviation version is meaningful.
- **Permutation test.** Treats years as exchangeable, so it ignores trend and
  autocorrelation; the plan's detrended outcome (`burn_detr`) addresses the
  trend.
