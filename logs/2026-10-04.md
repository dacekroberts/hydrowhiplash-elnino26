## Problems and fixes

- ERA5 month lag: October with a 3-month lag first returned June instead of
  July. Fixed in src/download_era5.py; covered by tests.
- The `gh auth login` command first given used bash syntax; PowerShell
  rejected the quoted path without the `&` call operator. Rerun as
  `& "C:\Program Files\GitHub CLI\gh.exe" auth login`.
- First ERA5 run refused all 77 years (HTTP 403): only the CDS site terms
  had been accepted, not the dataset's CC-BY licence. Fixed by accepting it
  on the Download tab; the downloader now stops at the first 401/403
  instead of trying every year.
- One file write to `src/download_era5.py` failed with "Invalid argument"
  (Errno 22), likely a transient lock; the file was intact and the edit was
  re-applied.

- The ERA5 grid stores 35.5N as 35.499999999999645, which would have decided
  the NorCal/SoCal split by float noise. Fixed by snapping coordinates on
  load; a test checks an edge row lands in exactly one region.
- `conda run python -c` rejects multi-line scripts, and a heredoc piped to
  `conda run` silently did nothing (stdin not passed); scratch scripts went
  to the session scratchpad instead.
- Python `write_text` on Windows wrote CRLF line endings into edited files;
  converted back to LF. A blanket conversion loop also hit the three PNG
  figures and corrupted them; they were regenerated by re-running the
  notebook.
- The notebook's exact-equality overlap check failed on float32 rounding
  between the two downloads; replaced with a tolerance (DECISIONS.md).
- The first estimate for the north download (2-2.5 hours) came from slow
  first requests; it took 60 minutes.
- Merging PR #2 with `gh pr merge 2 --squash --delete-branch` (GitHub CLI
  2.102.0) also tried to delete the local branch `side/methods-notices`,
  which was checked out in the side session's worktree

  worktree: its files were deleted and git unregistered it; only the empty
  folder remained ("Permission denied" on the folder itself). Committed work
  was intact (branch tip d72dede, merged in b2fd0b5; `side/pr-guide` intact
  locally and on GitHub); `git fsck` found no dangling staged content beyond
